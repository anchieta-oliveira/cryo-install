# cryo-install
## English:

**cryo-install** is a project focused on creating and organizing reproducible environments for **cryo-EM** tools and applications.

The goal is to simplify the installation, configuration, and execution of different software, mainly through **Docker** and isolated environments, reducing issues related to dependencies, library versions, CUDA, and system configuration.

The project aims to make processing environments easier to install, reproduce, and share across different machines and infrastructures.

---

## PT-BR

**cryo-install** é um projeto voltado à criação e organização de ambientes reprodutíveis para ferramentas e aplicações de **cryo-EM**.

A proposta é facilitar a instalação, configuração e execução de diferentes softwares, principalmente por meio de **Docker** e ambientes isolados, reduzindo problemas relacionados a dependências, versões de bibliotecas, CUDA e configuração do sistema.

O projeto busca tornar os ambientes de processamento mais fáceis de instalar, reproduzir e compartilhar entre diferentes máquinas e infraestruturas.
